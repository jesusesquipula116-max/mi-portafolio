# Página web de Juan

Proyecto de página personal para la práctica de programación.

Archivos:
- index.html
- styles.css

Para abrirla:
1. Abre la carpeta en Visual Studio Code.
2. Abre index.html.
3. Puedes usar un navegador para visualizarla.

Después podemos subir este proyecto a GitHub y desplegarlo con Dokploy.
